---
title: Install on Windows
description: Install RoN Mod Manager on Windows 10 and 11 with the Setup .exe.
---

RoN Mod Manager supports 64-bit Windows 10 and 11. There is no native macOS
build.

## Steps

1. Download the Windows Setup .exe from the
   [downloads page](/RoNModManager-site/downloads/). The file name ends in
   `_x64-setup.exe`.
2. Run the installer and follow the setup wizard.
3. Launch RoN Mod Manager from the Start menu.
4. Complete the setup wizard by linking mod.io, Nexus Mods or both. See
   [getting started](/RoNModManager-site/docs/getting-started/) for details.

## Updating

Download the newer Setup .exe from the
[downloads page](/RoNModManager-site/downloads/) and run it. Your mods,
profiles and settings carry over.

## Troubleshooting

If Windows SmartScreen warns about an unrecognised app, confirm you downloaded
the file from this site or the linked GitHub release, then choose to run it
anyway. For anything else, see
[troubleshooting](/RoNModManager-site/docs/troubleshooting/).
