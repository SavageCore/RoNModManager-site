This guide takes you from download to your first installed mod.

## 1. Install the app

Pick your system on the [downloads page](/RoNModManager-site/downloads/):

- **Windows:** run the Setup .exe. See [Install on
  Windows](/RoNModManager-site/docs/installation/windows/).
- **Linux:** use your distro's native package, the AppImage or Flatpak. See
  [Install on Linux](/RoNModManager-site/docs/installation/linux/) or
  [Install with Flatpak](/RoNModManager-site/docs/installation/flatpak/).

## 2. Link a mod source

On first launch the setup wizard asks for your mod source credentials:

- **mod.io:** paste your API access key and a personal access token from
  [mod.io/me/access](https://mod.io/me/access). You can skip this and add it
  later in settings.
- **Nexus Mods:** paste your personal API key from your
  [Nexus API settings](https://www.nexusmods.com/settings/api-keys).

Keys stay on your machine inside the app config. Never paste them into this
website, a screenshot or a chat message.

## 3. Install your first mod

1. Find a mod on mod.io or Nexus Mods and copy its page link, or download the
   mod file to your computer.
2. In the app, open Add Mod: use the Mod Link tab for a page link or the
   Local File tab for a downloaded file.
3. Confirm the mod appears in your installed list.
4. Launch the game modded from the app and check the mod loads.

The optional [browser userscript](/RoNModManager-site/docs/userscript/) adds
a one-click install button on mod pages.
