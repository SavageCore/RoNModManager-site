title: Profiles and collections
description: Organise mods into profiles and collections for different squads and servers.
---

Profiles and collections keep different loadouts separate, so solo runs, co-op
nights and roleplay servers each launch with the right mods.

## Profiles

A profile is a named setup with its own enabled mods and launch options.
Switch profiles when you switch context, for example Default for everyday
play and Roleplay for a server with strict mod rules.

## Collections

A collection groups related mods inside a profile, such as a weapon pack, a
map set or a realism overhaul. Enable or disable the whole collection at once
instead of toggling mods one by one.

## Modpacks

A modpack is an exportable snapshot of your mods and collections for sharing
with others. See [hosting
modpacks](/RoNModManager-site/docs/modpacks/hosting/) to publish one, or
paste a shared modpack URL into the app modpack panel to install it.

Adding a new modpack URL while one is already configured appends mods to the
existing installation, so check which URL is active before you start.
